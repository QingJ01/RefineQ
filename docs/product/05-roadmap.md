## P2 —— 赛后

按"先还债、再补感知、后扩能力"排序：

1. **收敛双路由。** 前端已只走 `/workspaces`，把 `/projects` 系列路由与重复的服务装配下线，删掉 `api/app.py` 里的双份实例化。
2. **错题与间隔复习界面化。** 复习会话机制已有（3 天 / 1 天注入），把"待复习队列"做成显式视图，配合收藏题形成错题本。
3. **主动触达。** 每日计划提醒（邮件或 PWA 通知），Agent 从"打开才工作"变成"到点来找你"。
4. **学习报告分享。** 报告卡生成可分享图片（去敏），承担口碑传播。
5. **资料形态扩展。** 手写笔记拍照（走已有 OCR 通道）、音频课程转写。
6. **多用户验证。** 邀请 5–10 位相似用户,把"首次价值时间 ≤ 5 分钟"从设计目标变成测量指标。
