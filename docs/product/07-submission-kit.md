## 2. Agent 简介

### 短版（若表单限 100 字内）

> RefineQ 为一位正在备考【具体考试】的学习者而做。TA 有讲义和笔记，缺的是有人拿这些资料出题、判分、指出薄弱点。对 RefineQ 说一句目标，它建立学习空间、生成到考试日的计划，用你自己的资料主动出题，判分后更新掌握证据。聊过不算学会，答对才算。

### 长版

> RefineQ（砺问）最初为【化名】设计：【身份】，【日期】考【具体考试】，手里有【资料描述】。TA 用 AI 问过问题，"当时懂了，过几天做题还是不会"；资料在网盘里躺着，没有工具拿它们验证掌握情况。
>
> RefineQ 接住这条完整链路：用一句话说明目标，系统自动建立或切换学习空间，识别科目、截止日期和每日可用时间，当场生成学习计划；上传 PDF、DOCX、TXT、Markdown 资料后，题目从资料生成并标注原文依据；作答后按结构化标准判分，指出优势、缺口和误区，掌握度由作答证据更新，复习自动排期。学习教练对话自动携带当前目标、计划、薄弱点和资料引用。
>
> AI 服务不可用时，出题、判分与学习记录降级为确定性流程，进度不丢。有自己的资料、有截止日期、需要确认"是否真正掌握"的备考者，都能直接使用。

填写提醒：两版都以人物开头，不要改成"面向广大学生"之类的说法；【】内容必须与访谈记录一致。

## 3. 使用方式（给评审的操作说明）

> 1. 打开体验链接，注册账号（无需邀请码）。也可用演示账号直接看已有学习状态：`learner@refineq.local` / 【部署时设定的密码】。
> 2. 在首页输入框用一句话说明目标，建议带上考试和时间，例如："10 月 25 日考计算机组成原理期中，每天能学 90 分钟。"系统会自动建立学习空间并生成计划。
> 3. 进入"资料"上传你的讲义或笔记（PDF / DOCX / TXT / Markdown），稍候即可在搜索中命中原文。
> 4. 回到"今日"点击开始练习：题目基于你的资料生成，可调难度、换题、收藏。
> 5. 提交回答后查看判分：分数、缺口、误区、资料引用与掌握度变化；复习会自动排进计划。
> 6. 在"进步"页查看各主题掌握度与完整证据记录；随时向学习教练提问，对话自动带上你的目标与薄弱点。
>
> 管理说明:模型、Embedding、OCR 与对象存储由管理员在后台统一配置，普通用户无需任何 API Key。

## 5. 源码 ZIP

```powershell

# 2. 密钥扫描

# 3. 打包
git archive --format=zip -o ..\refineq-src.zip HEAD

# 4. 抽查压缩包
# 解压到临时目录，确认没有 .env、data/、密钥、真实用户资料；
```
