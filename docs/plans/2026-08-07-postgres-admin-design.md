# PostgreSQL、pgvector 与管理后台设计

## 目标与范围

RefineQ 将从用户目录下的 JSON、SQLite FTS 和分散的个人模型配置，迁移到以 PostgreSQL 为唯一业务数据源的部署架构。数据库启用 pgvector 扩展：账户、角色、学习记录、Agent 会话和平台配置进入 PostgreSQL；资料元数据与文本分块进入专用表；原始上传文件继续通过统一对象存储接口保存。管理员后台集中配置大模型、Embedding、OCR 与 S3 兼容对象存储，普通学习者不再接触平台密钥。

本次选择“兼容记录表 + 专用知识表”，而不是立即把所有学习领域对象完全规范化。通用 `records` 表以 `(owner_id, collection, record_id)` 为唯一键，使用 JSONB 保存现有领域结构，并保留 schema/version 乐观锁。这样现有 Project、Workspace、Learning、Session 服务无需重写，迁移风险最低。知识库使用 `materials`、`material_chunks` 表，分别保存元数据、文本、全文检索向量和 pgvector embedding。账户、平台设置、审计日志使用明确的关系表。

备选方案有两种：全面关系建模能获得最严格的数据库约束，但会显著扩大黑客松期间的领域重写与回归范围；直接使用云端 BaaS 开发更快，但会绑定特定平台并增加演示环境依赖。当前方案在可部署性、开发速度和后续演进之间更平衡。

## 权限与配置中心

用户增加 `role` 字段，取值为 `learner` 或 `admin`。JWT 仍只保存用户标识与到期时间，每次鉴权都从数据库读取当前角色，避免降权后旧令牌继续拥有管理员权限。管理员 API 使用独立依赖校验角色；所有平台配置写操作记录管理员、配置类型、动作和时间，但不记录密钥正文。

平台配置分为四组：聊天模型、Embedding、OCR、对象存储。每组保存启用状态、非敏感参数和 Fernet 加密后的凭据。API 返回时只提供 `configured` 与末四位提示。后台提供保存、停用和连接测试；连接测试在后端执行，并继续受 HTTPS、主机白名单、超时和错误脱敏约束。聊天与 Embedding 使用 OpenAI 兼容接口；OCR 使用 OpenAI 兼容视觉接口；对象存储使用 S3 兼容协议，因此可覆盖 OpenAI、DeepSeek、通义兼容接口、Cloudflare R2、阿里云 OSS、腾讯云 COS 和 MinIO 等常见部署。

管理员账号通过一次性 CLI 初始化，默认邮箱为 `qingj1314@163.com`。CLI 支持幂等创建或提权，密码从显式参数或安全交互输入，项目不保存明文。此次本地初始化会生成随机高强度密码并只在交付信息中显示一次。

## 检索、降级与文件流

上传文件先经过现有文件类型、大小和解压炸弹防护。文字型 PDF、DOCX、TXT 和 Markdown 继续本地解析；当本地抽取为空或判定为扫描件、且 OCR 已启用时，才调用 OCR。原始文件由存储接口写入本地磁盘或 S3 兼容对象存储，数据库只保存 storage key、哈希与元数据，避免把大二进制直接放入 PostgreSQL。

文档切片写入 PostgreSQL 后，如果 Embedding 已启用，批量生成向量并保存到 pgvector；查询时融合 PostgreSQL 全文检索分数与余弦相似度。Embedding 未配置、调用失败或历史分块尚未向量化时，系统仍返回全文检索结果，不阻断上传和学习。后台展示各能力的配置与健康状态，让管理员能区分“未配置”“可用”和“最近测试失败”。

旧数据迁移脚本按先写数据库、后校验数量的方式导入 `auth.json`、通用 JSON 记录、模型配置与 SQLite 知识索引。原文件不自动删除，迁移报告包含导入、跳过和失败数量，便于回滚。生产运行不再回读旧文件；`REFINEQ_DATA_ROOT` 只保留本地对象、临时解析文件和迁移来源。

## 错误处理与验证

数据库初始化使用版本表和幂等 DDL，启动时要求 PostgreSQL 可连接且 pgvector 扩展可用；健康检查分别报告 API、数据库、向量扩展和外部能力状态。事务边界覆盖记录的并发更新、资料元数据与分块替换、管理员配置更新。外部服务错误统一转换成稳定错误码，响应不泄露 API Key、数据库 URL 密码或对象存储密钥。

测试分三层：SQLite 兼容引擎覆盖仓储、身份、权限与管理 API 的快速单元/集成测试；纯函数测试覆盖混合分数、配置加密与迁移转换；PostgreSQL 集成测试通过环境变量连接真实 pgvector 实例，没有实例时明确跳过。交付门槛包括 Python 全测、Ruff、秘密扫描、前端 Vitest、ESLint、Next.js 构建，以及 Compose 配置静态校验。本机没有 Docker，因此真实 pgvector 容器验证会如实标注为环境限制，不能用 SQLite 结果冒充。
