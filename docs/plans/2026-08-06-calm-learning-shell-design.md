# RefineQ 极简学习应用壳设计

## 目标

将当前偏编辑排版、装饰性较强的界面，重构成接近豆包桌面端使用感受的极简学习工作台。保留 RefineQ 的学习空间、计划、AI 出题判分、资料、证据和学习 Agent，不复制豆包品牌资产或文案。

## 设计方向

- 语气：安静、轻盈、专注，像每天都会打开的个人学习工具。
- 记忆点：一枚蓝色圆角 `R` 标识，以及围绕“今天想学什么？”构建的中央学习输入框。
- 色彩：近白主画布、冷灰侧栏、深灰正文、单一学习蓝强调色；成功和提醒色只用于状态。
- 字体：继续使用本地托管的 Manrope Variable，并以系统中文字体回退；移除大面积衬线展示字。
- 形状：12–20px 圆角、1px 低对比描边、克制阴影，不使用粗黑边、错位阴影、网格纸或轨道装饰。

## 信息架构

### 登录

单列居中登录卡片。顶部为 RefineQ 标识与一句产品说明，下面是登录/注册切换和表单。语言切换放在页面右上角或进入应用后侧栏底部。

### 学习首页

左侧固定应用侧栏，主区域中央显示问候、学习意图输入框和自动识别说明。最近学习空间作为低密度列表置于输入框下方。

### 学习工作区

侧栏上部显示品牌，中央为学习导航，下部显示当前学习空间、语言和退出。主区域顶部显示当前空间标题、目标和总体掌握度；计划、练习、资料、证据、Agent 分区复用统一内容容器。

### 移动端

侧栏压缩为顶部栏，学习导航成为水平滚动的圆角标签。内容保持单列，操作按钮和输入区域适配触控尺寸。

## 组件规则

- 主按钮：蓝色实底、白字、12px 圆角，无大写英文和重阴影。
- 次按钮：浅灰或透明底，悬停时提升边框对比度。
- 内容卡片：白底、浅边框、16px 圆角、极浅阴影。
- 标题：短中文主标题配一行灰色说明；英文 eyebrow 仅作为小型辅助信息。
- 输入框：浅灰底或白底，完整圆角边框；对话输入为宽大的组合式 composer。
- 状态：错误、成功、待改进均使用柔和底色和图标，避免只依赖颜色。

## 保持不变

- API、状态恢复、自动学习空间路由、上传、出题判分、学习证据和 Agent 对话逻辑。
- 现有 `data-testid`、可访问名称和中英文翻译入口。
- Next.js 16、React 19、Lucide、Vitest 和 Playwright 技术栈。

## 验收

- 登录、空学习首页和已有学习空间的所有主要页面具有统一应用壳。
- 1440px 桌面和 390px 移动视口无水平溢出，主要动作清晰可达。
- 原有组件测试和端到端学习旅程继续通过。
- 生产构建、Lint、Vitest 和 Playwright 均通过。
