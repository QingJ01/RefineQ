# 隐式学习空间与 AI 练习设计

## 目标

RefineQ 对用户只呈现一个长期陪伴式学习 Agent。用户通过自然语言或上传资料开始学习，系统自动识别正在学习的方向，创建或切换到对应的隐式学习空间。用户不再创建、命名或管理“项目”。

本阶段同时把练习从固定模板和关键词判分升级为基于个人资料、薄弱点和难度状态的 AI 出题与结构化智能判分。

## 产品原则

1. **无项目门槛**：注册后直接看到“今天想学什么？”。
2. **自动但可纠正**：高置信度时自动切换；低置信度时保留最近空间并显示判断依据，用户可通过最近学习列表或自然语言纠正。
3. **学习上下文必须隔离**：数学、英语和编程资料不能进入同一次检索或掌握度计算。
4. **AI 不可用时仍能学习**：未配置模型或模型暂时失败时，空间路由、基础练习和确定性判分都有降级路径。
5. **所有学习判断可解释**：问题记录来源，评分返回得分、正确点、遗漏点、误区、反馈与引用。

## 用户流程

1. 用户注册或登录，浏览器安全地恢复当前会话。
2. 首页显示一个 Agent 输入框和“最近学习”，不显示项目表单。
3. 用户输入“我要复习高数极限，14 天后考试”或上传资料。
4. 空间路由器结合消息、文件名、资料摘要、最近空间和历史关键词做出 `created`、`switched` 或 `reused` 决策。
5. 新空间自动生成标题、学习目标、主题和默认学习节奏；已有空间更新最后活动时间。
6. 页面进入对应学习上下文，恢复计划、资料、掌握度、证据和 Agent 会话。
7. 用户请求练习时，系统从最低掌握主题和相关资料中生成问题；提交答案后得到结构化评分并更新掌握度、难度和证据。

## 架构

### 隐式学习空间

用 `workspace_id` 作为所有学习状态的隔离键。`WorkspaceRepository` 存储：

- `id`、`title`、`subject`
- `goal`、`topics`、`keywords`
- `created_at`、`last_active_at`
- `routing_summary`，用于解释自动切换

`WorkspaceRoutingService` 先用本地标准化、学科词典和词项重合计算候选；模型已配置时，再要求模型返回受 Pydantic 约束的 JSON 决策。模型输出只能从已有候选中选择，或建议创建新空间，不能直接访问文件系统或修改状态。无模型时使用确定性路由。

### 结构化学习智能

新增 `LearningIntelligenceService`，复用 OpenAI-compatible 设置，但与对话 Agent 分离。它提供两个受约束操作：

- `generate_question`：输入主题、难度、掌握度和可信资料片段，输出题目、参考答案、评分标准、解释与引用。
- `grade_answer`：输入问题、参考答案、评分标准、学生答案和资料片段，输出 0–100 分、是否通过、正确点、遗漏点、误区、反馈与引用。

模型响应先抽取 JSON，再由 Pydantic 严格验证；引用必须存在于本次检索结果中。解析失败、超时或未配置模型时，使用确定性降级结果，并在响应中标记 `mode="fallback"`。

### API

- `GET /workspaces`：按最近活动时间返回学习空间。
- `POST /workspaces/resolve`：根据自然语言自动创建或切换空间。
- `GET /workspaces/{workspace_id}/snapshot`：一次恢复空间、计划、进度、证据和资料。
- `/workspaces/{workspace_id}/learning/*`：计划、练习、评分和证据。
- `/workspaces/{workspace_id}/materials/*`：上传、检索和资料状态。
- `/workspaces/{workspace_id}/agent/chat`：带当前空间上下文的对话。

旧 `/projects/*` 不再由新前端调用。迁移工具把已有 `projects` 记录和 `project_id` 字段转换为 `workspaces` / `workspace_id`，并保留备份优先、不覆盖目标数据的规则。

## 前端状态与恢复

浏览器只持久化访问令牌和最后活动的 `workspace_id`。启动时先调用 `/auth/me` 校验令牌，再请求空间列表和快照；失效令牌立即清理。学习数据本身始终以后端为准。

主界面包含：

- 首次进入的 Agent 启动页
- 最近学习空间
- 当前空间的今日计划、资料、证据和 Agent
- AI 练习卡，显示难度、资料依据和结构化评分反馈

上传资料后刷新快照，刷新页面后仍能看到历史资料和进度。

## 错误与安全

- 自动路由低置信度时不静默创建大量空间；优先复用最近空间并返回可见说明。
- 模型密钥按用户保存，不允许一个账户修改另一个账户的设置。
- 上传资料作为不可信内容包裹，不能覆盖系统指令或评分规则。
- 模型网络错误映射为稳定错误码；练习接口自动降级，不让一次模型失败阻断学习。
- 所有 workspace 查询仍从认证身份派生 owner，不接受客户端传入 owner_id。

## 验收标准

1. 注册后无需创建项目即可输入学习意图并得到学习空间。
2. 同一主题会复用原空间，不同主题会自动创建或切换。
3. 页面刷新和重新登录后能恢复最近学习空间、资料和进度。
4. 配置模型时，问题与评分走结构化 AI；未配置模型时仍可完成练习。
5. 评分响应包含得分、反馈、正确点、遗漏点、误区和合法引用。
6. Python、Web、真实浏览器流程和容器构建全部通过。
