# RefineQ 登录首页层次增强设计

## 目标

解决登录首页说明文字偏小、左侧内容显得空的问题，同时保持 RefineQ 已确定的简洁消费级风格，不增加营销式功能卡或复杂插画。

## 方案

- 左侧说明“一个 Agent，持续理解你的目标、资料、练习和进步。”提升至 19px、适度增加字重，并限制在舒适阅读宽度内。
- 登录卡内同一句辅助说明提升至 14px，避免成为几乎不可读的注脚。
- 将原来的两个胶囊卖点替换为一条学习记忆轨迹：目标、资料、练习、进步。四个节点通过细线连接，蓝色用于当前能力，杏色用于进步终点。
- 左侧背景加入低对比点阵和柔和环境光，只增强空间层次，不与主表单争夺注意力。
- 移动端隐藏完整轨迹，保留更大的表单说明，避免首屏过长。

## 验收

- 组件输出四个学习轨迹节点，并使用中英文翻译键。
- CSS 契约固定左侧说明为 19px、登录卡说明为 14px。
- 桌面 1440px 和移动 390px 无溢出，登录与注册流程不变。
